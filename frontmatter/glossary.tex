% Glossary: one \item per term, in alphabetical order.
\indexedsection{Glossary}

\begin{description}
  \item[Artifact] A component of a recorded EEG signal that does not originate from brain activity, such as interference from eye movements, muscle activity, or poor electrode contact.
  \item[Asynchronous control] A BCI operating mode in which the user decides when to issue a command, rather than responding to an external cue.
  \item[Consumer-grade EEG headset] A portable, relatively low-cost EEG device intended for use outside the laboratory, typically with fewer channels and lower signal quality than research-grade systems.
  \item[Emotiv EPOC X] A consumer-grade, wireless EEG headset produced by Emotiv and used in this dissertation to generate control commands.
  \item[End-to-end response time] The time between the user producing a command and the vehicle executing the corresponding physical action, including command generation, communication, and actuation.
  \item[False activation] A command detected and executed by the system although the user did not intend to issue it.
  \item[Feature extraction] The stage of signal processing that derives informative measures from the acquired brain signals for subsequent classification.
  \item[Jitter] The variation in latency between successive messages.
  \item[Latency] The time taken for a message or command to travel from its source to its destination.
  \item[Mental Commands] An Emotiv software feature in which the user trains specific mental actions that are subsequently recognized and output as commands.
  \item[Missed command] A command that the user intended to issue but that the system failed to detect or execute.
  \item[Non-invasive BCI] A BCI that records brain activity without surgery, using sensors positioned on the scalp.
  \item[Publish-subscribe] A messaging model in which senders publish messages to named topics and receivers subscribe to the topics they are interested in, usually through an intermediary broker.
  \item[Quality of Service] In MQTT, the level of delivery guarantee agreed for a message: at most once, at least once, or exactly once.
  \item[Round-trip time] The time taken for a message to travel to its destination and for a response to return to the sender.
  \item[Throughput] The amount of data or number of messages successfully transmitted per unit of time.
\end{description}
